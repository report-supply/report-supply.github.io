# Supplier Extra Info

This folder stores optional extra information for each supplier.

`data.json` uses the supplier ID from `suppliers-info.txt` as its key.

Fields:
- `supplierName` — supplier name for reference.
- `photo` — direct image URL for the supply office photo.
- `mapLocation` — Google Maps URL.
- `phoneNumber` — supplier office phone number.
- `whatsappLink` — WhatsApp channel/group URL.

Leave a field empty when the information is not available.
